    How it stays current

    The service checks the original index when its hourly cache expires. The feed includes the 60 most recent listed essays. It keeps the original order and uses essay URLs as permanent IDs.

    The index does not supply publication dates. This feed leaves those dates out. If the index is unavailable or fails validation, a previous snapshot stays available with its original check time.
